# 视频 + 音频 → 指定人物对口型（H3 AudioDrive 实测，2026-11-17）

> 场景：现成镜头里两个人，只要左边那位改说一段指定配音，右边那位保持不动。成员包见 `verified/H3-视频加音频-指定人物对口型-4步turbo一采`。

## 1. 先分清三条路（选错就白跑）

| 路线 | 输入 | 结果 | 什么时候用 |
|---|---|---|---|
| **H3 单图数字人**（`wf_2084814218431385601`） | 一张图 + 音频 | 整段重建，原表演全丢 | 干脆重做成口播 |
| **H3 视频 + 音频**（本包） | 原片 + 音频 | 整帧重画，构图/动作/坐姿沿用原片，细节会漂 | 要保留原片镜头语言，能接受身份细节轻度改写 |
| **InfiniteTalk**（`verified/InfiniteTalk-...`） | 原片 + 音频 | 只改嘴，其余像素基本不动 | **单张脸**的近景；双人同框会串脸 |

判据一句话：**要「另一个人不许动」且两个人同框，走 H3 视频+音频 + 提示词分工；要「右半边像素几乎不变」，只能靠遮罩重绘或 InfiniteTalk 单脸。**

## 2. 接线契约（少一根线就不出声）

```
VHS_LoadVideo ─→ MiniMaxH3ReferenceToVideo.ref_videos.ref_video_0   # 表演/构图骨架
LoadImage(首帧) ─→ ...ref_images.ref_image_0                        # 身份锚
LoadAudio ─────→ VRGDG_MiniMaxH3AudioDrive.source_audio
VAE(音频) ─────→ VRGDG_MiniMaxH3AudioDrive.audio_vae
ReferenceToVideo.LATENT ─→ AudioDrive.av_latent
AudioDrive.audio_driven_av_latent ─→ SamplerCustomAdvanced.latent_image
AudioDrive.original_audio ────────→ VHS_VideoCombine.audio          # 成片音轨 = 上传那条
```

- **音频不进提示词**：`<d>` 只是对齐提示，真正驱动口型的是 `av_latent` 里的音频潜空间。只写台词不接 AudioDrive，嘴仍然按模型自己的节奏动。
- **成片音轨必须取 `original_audio`**（AudioDrive 第 1 槽）。取 `ref_video_audio_0` 会变成原片原声。
- **不要接 `ref_video_audios.ref_video_audio_0`**：换台词时接了等于让模型去复用原声。

## 3. 帧数：17k+5 和「参考视频长度」必须对上

- `length` ∈ {56, 73, 90, 107, 124…} = 17k+5；音频秒数按 `round(s×24)` 后向**上**取最近的网格。
- 本片音频 3.336s → 90 帧 = 3.750s，**尾部多 0.41s 静音**，交付前裁回源镜头长度（81 帧 / 3.375s）。
- 源片帧数不在网格时，先 `ffmpeg -vf "tpad=stop_mode=clone:stop_duration=X" -frames:v N` 克隆末帧补齐，再当 `ref_video`。**`frame_load_cap` 必须等于 `length`**，不一致会尾部补黑或报长度错。
- 想避免补静音，反过来先裁音频到网格内（例如裁到 3.042s 配 73 帧）。

## 4. 双人同框：怎么让旁边那位闭嘴

- 说话人写 **`<Subject N> (Sx)` + `<d>[Chinese] 台词</d>`**，`<d>` 紧贴这个人的描述。
- 听者只写**一句正向静止嘴形**：「his lips, jaw and chin stay completely still in every frame, his mouth resting in the same slightly parted shape it holds in `<Video 1>`, as if that face were a painted detail of a still picture」，再加一句「he is a listener in this shot」。
- **否定句 ≤2 句**：`never open / never twitch / never chew` 连写会把注意力全拉到嘴上，反而动（同 `references/画外音与闭嘴控制.md` §2.2）。
- 还压不住就拆：该镜单独跑一条「全场静默」版，说话镜另跑，后期按帧拼。

## 5. 4 步 turbo 的代价（实测数字）

- 构图、机位、坐姿、服装大形都在；**身份细节会漂**：胡须变短、官帽纹样改写。
- 首帧 vs 源片首帧 **PSNR Y 17.17 dB**（同族换人包通常在 30 dB 以上）——这就是「重画」而非「改嘴」的证据。
- 要拉回身份：LoRA 改 bypass（mode=4）+ 20 步一采，成本约 4 步的 5 倍。
- **平台水印会被洗掉**：源片右上角「RunningHub AI生成」在成品里消失。

## 6. 验收怎么判（脚本能算的三项）

1. **旁人是否静止**：`ffmpeg -i out.mp4 -vf "crop=W:H:X:Y,tblend=all_mode=difference,signalstats,metadata=print:key=lavfi.signalstats.YAVG:file=-"` 取旁人所在半区，YAVG 全程 <1/255 视为静止（本片 0.020–0.746）。
2. **嘴是否真在动**：`select='not(mod(n,6))',crop=脸,scale=…,tile=5x3` 出 15 格拼条，肉眼看是否张开/收圆/闭合都有。
3. **音轨是否就是上传那条**：`silencedetect=noise=-40dB:d=0.15`，句尾静音起点应≈音频时长（本片 3.194s vs 3.336s）；`volumedetect` 记录电平（−31.4 / −11.1 dB）。
