# 音频补静音 + 时长凑 17k+5 帧（H3 音频驱动通用片段）

**用途**：任何「音频决定视频长度」的 H3 链路（AudioDrive / 语音克隆 / 配音对口型），把任意长度的音频变成 H3 能接受的帧数，并控制片头/片尾留白。

**来源**：`verified/H3-音频驱动数字人-语音克隆-TTS补静音`（workflowId `2086995655117070338`），2026-11-18 读图核对 + `/object_info` 核实节点定义。
**状态**：节点定义已核实；这条接线**未实跑**。

## 1. 三个节点

| 节点 | 来源 | 作用 | 输入 → 输出 |
|---|---|---|---|
| `AudioBeforeAfterSilence` | ComfyUI_Lam（显示名「音频前后加静音」） | 前后补静音 | `audio: AUDIO`、`before: FLOAT(秒, 默认 0)`、`after: FLOAT(秒, 默认 0)` → `AUDIO` |
| `SoundFlow_GetLength` | ComfyUI-SoundFlow（显示名 `Audio Get Length`） | 量音频时长 | `audio: AUDIO` → `FLOAT`（秒） |
| `ComfyMathExpression` | 内置 utilities | 把秒数算成合法帧数 | `expression: STRING`、`values.a`（自动增长槽）→ `FLOAT` / `INT` / `BOOL` 三个输出 |

## 2. 接线铁律：先补静音，再测长度

```
配音/参考音频 ──► AudioBeforeAfterSilence(before, after) ──┬──► SoundFlow_GetLength ──► ComfyMathExpression ──►(INT) H3.length
                                                          ├──► VRGDG_MiniMaxH3AudioDrive.source_audio
                                                          └──► PreviewAudio（试听）
```

- `GetLength` **必须**接在补静音之后。接在之前 = 算出的帧数短了 `before+after` 秒，成片尾部被裁。
- `source_audio` 也用补过静音的那一路，保证「算长度用的音频」和「驱动口型用的音频」是同一份。

## 3. 帧数公式

H3 的 `length` 必须是 `17k+5`（5、22、39、56 …）。一行表达式（照抄，`a` 是补静音后的秒数）：

```
max(5, round(a * 24)) + (5 - (max(5, round(a * 24)) % 17)) % 17
```

- `round(a*24)`：秒 → 帧（24fps）。
- `max(5, …)`：H3 最小 5 帧，短音频也不报错。
- 后半段把结果抬到最近一个「模 17 余 5」的数。
- 取 **第 2 个输出（INT，槽位 1）** 接 `length`；接槽 0（FLOAT）类型不符，接槽 2（BOOL）更错。

验算：

| 配音 | 补 0.4s 后 | round(×24) | 结果 | 结果 % 17 |
|---|---|---|---|---|
| 8.00 s | 8.40 s | 202 | 209 | 5 |
| 3.336 s | 3.736 s | 90 | 90 | 5 |
| 0.10 s | 0.50 s | 12 | 22 | 5 |
| 14.00 s | 14.40 s | 346 | 362 | 5（346 % 17 = 6，补 16 帧） |

> 公式里的 `%` 是 Python 语义（结果非负），别用 JS 手算 `-10 % 17`（JS 得 −10，Python 得 7）。14.4 秒那行就是最容易算错的一档：要补 16 帧而不是 0 帧。

## 4. 参数怎么定

| 参数 | 建议 | 理由 |
|---|---|---|
| `before` | 0.2–0.5 s | 给口型起手留缓冲；这段会**进成片**，人物闭嘴站着，太长像卡住 |
| `after` | 默认 0 | 尾部静音会让 H3 生成一段无声定格；确实需要收尾留白再给 0.2 左右 |
| 采样率 | 24fps 对应 `*24` | 换 25fps 工作流要同步改系数，否则帧数与音轨错位 |
| `length` 上限 | 看显存 | 17k+5 只是对齐规则，不解决显存；长音频要分段 |

## 5. 踩坑

1. **秒 ≠ 帧**：`before` / `after` 单位是秒（FLOAT，step 0.01），别填 10（那是 10 秒不是 10 帧）。
2. **补静音会改总时长**：0.4s 前补让 8 秒配音变 8.4 秒，帧数按 8.4 算；如果先按 8 秒算再补，尾部会丢 10 帧。
3. **`GetLength` 输出是 FLOAT**：直接接 `length` 可能被拒；中间这层 Math 节点同时兼做取整。
4. **参考音频截取与补静音是两件事**：`AudioCrop` 截样本给 TTS 克隆用；补静音是给 H3 成片用的，别把 `AudioCrop` 的输出直接当 `source_audio`。
5. **`ComfyMathExpression` 的 `values` 是自动增长槽**：接 `a` 用 `values.a`；节点里可能残留 `b`–`z` 空槽，不影响执行但会让界面变长，写完可以删。
