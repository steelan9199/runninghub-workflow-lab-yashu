# 三视图提示词经验（MOSS 无框版为主，Qwen 版通用）

适用：白底三格角色三视图——左＝肩线以上头像、中＝无头躯干与腿、右＝背面全身。
来源：2026-11-19 多轮实测（Qwen 3 次跑偏 → MOSS 无框版跑通；老板确认三条美女提示词可用）。

## 一、骨架固定为六段，顺序不要动

```
① 版式段：真实摄影，纯白背景 #FFFFFF，角色三视图设定图，整张画布横向三等分，从左到右依次三格，三格等宽，格与格之间没有分隔线、没有文字、没有编号、没有水印。三格同一位人物、同一套服装、同一双鞋、同一光线，人物对齐同一脚底线。
② 人物段：年龄、肤色、脸型、发型发色、妆容，然后一句「穿 A、B、C、D」（服装三层：颜色+品类+材质）。
③ 左格：正面头像特写，只出现头部与双肩，肩线以下即出画，不出现胸口、手臂与裙身，头像明显大于中格与右格。
④ 中格：同一套服装的正面，只有躯干与双腿，从肩线开始向下，没有头部、没有头发、没有脖颈、没有脸部区域，{领口品类}在画面顶部清晰可见，双脚踩地。
⑤ 右格：背面全身，完整带头与{发型}，看不到面部五官，{外套/裙背面}平顺，{裤脚/裙摆}与鞋完整入画。
⑥ 质感段：真实皮肤纹理，{面料}细节清晰，无描边、无插画感。
```

总长约 350–400 字。再长会稀释关键约束。

## 二、五条反直觉的写法（每条都有失败证据）

| # | 别这么写 | 要这么写 | 为什么 |
|---|---|---|---|
| 1 | 「无头人台」「服装展示用人台」 | 「只有躯干与双腿，从肩线开始向下」 | 「人台」会被画成**保留长发 + 一块无特征灰面**的人（2026-11-19 实拍），灰面还会成为下游换人的"面部遮挡"先验 |
| 2 | 中格只写「没有头部」 | 加一句「**{领口}在画面顶部清晰可见**」 | 给模型一个可见起点，它就不会往上补脖子与下巴；这是中格成功与长头的分水岭 |
| 3 | 在人物段写身高（"身高约 172"） | 身高一律不写 | 身高会被当成整图裁切/构图参数，左格直接被拉成半身或全身（Qwen 版连续 3 次翻车的主因） |
| 4 | 「胸口以上特写」「下缘止于锁骨」 | 「只出现头部与双肩，**肩线以下即出画**」 | 长度词（一寸、手掌）模型无法执行；"某线以下即出画"是可执行的构图动作 |
| 5 | 三格各写各的服装 | 三格**逐格点名同一件外套/领口** | 只写一次，中格必丢外套；三格服制不一致是最常见的废图原因 |

## 三、失败诊断表

| 现象 | 先查 | 改法 |
|---|---|---|
| 左格掉到胸口/腰，甚至全身 | 人物段是否写了身高或半身词 | 删身高；左格保留「肩线以下即出画」+「头像明显大于中格与右格」 |
| 中格长出头发与灰脸 | 是否出现「人台」「无头」字样 | 换成「只有躯干与双腿」，并加「{领口}在画面顶部清晰可见」 |
| 中格长了脖子/下巴 | 缺领口锚点 | 同上，补领口句 |
| 中格丢外套 | 中格没点名外套 | 中格补「{外套}敞开/垂在两侧」 |
| 三格像三个人 | 三段服装词不一致 | 逐格对齐颜色+品类+材质 |
| 格间出现文字/编号/分隔线 | 版式段被删减 | 版式段六句一句都不能省 |

## 四、参数联动（MOSS 无框版）

- 画幅 1728×768（每格 576×768，16 的倍数），batch 4。
- 8 步 / cfg 1.1 / euler / simple（DMD 蒸馏版）。
- **cfg 1.1 下负向几乎不起作用**，真正压住构图的是正向的排除句（「不出现胸口、手臂与裙身」）。
- 负向保留 `grey face, grey mask, faceless, mannequin head`，只当兜底。

## 五、已跑通的样板（可直接改人物与服装复用）

```text
真实摄影，纯白背景 #FFFFFF，角色三视图设定图，整张画布横向三等分，从左到右依次三格，三格等宽，格与格之间没有分隔线、没有文字、没有编号、没有水印。三格同一位人物、同一套服装、同一双鞋、同一光线，人物对齐同一脚底线。

人物：约 28 岁的中国女性，冷白皮肤，长鹅蛋脸，凤眼上挑，黑色低马尾垂到肩，裸妆，哑光豆沙唇，穿白色衬衫、黑色高腰包臀铅笔裙、黑色薄丝袜、黑色尖头细高跟。

左格：正面头像特写，只出现头部与双肩，肩线以下即出画，不出现胸口、手臂与裙身，头像明显大于中格与右格。

中格：同一套服装的正面，只有躯干与双腿，从肩线开始向下，没有头部、没有头发、没有脖颈、没有脸部区域，白衬衫领口在画面顶部清晰可见，双脚踩地。

右格：背面全身，完整带头与黑色低马尾，看不到面部五官，衬衫与包臀裙背面平顺，裙摆与鞋完整入画。

质感：真实皮肤纹理，棉布与丝袜细节清晰，无描边、无插画感。
```

## 六、已知不解决的部分

无框版仍是纯文生图，模型把整张画布当一个人画。若某次三条都不成立，不要继续加词——换带布局节点的版本（`MOSS三视图` 的布局备份版）用框的几何强制裁切，或退回 Qwen 备选包。
