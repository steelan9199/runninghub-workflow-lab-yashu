# H3 视频 + 音频 · 指定人物对口型 · 4 步 turbo 一采

**一句话用途**：拿一条**已经有表演的现成视频** + 一段**指定配音**，让画面里指定的那个人改说这段话，其余人物保持原样 —— 给短剧/推文镜头换台词用。

**和库里另外两条的区别（别选错）**：

| 需求 | 用哪条 |
|---|---|
| 一图 + 音频 → 整段重建成口播数字人（原表演全丢） | `corpus/wf_2084814218431385601.json`（单人）、`wf_2084818471610839041`（双人），提示词驱动 |
| 视频 + 音频 → **只改嘴**，动作与运镜锁死 | `InfiniteTalk-视频对口型-单人近景-4步锁动作`（单张脸；双人同框会串脸） |
| 视频 + 音频 → 指定某个人说话，**双人同框也能压住另一个人** | **本包**（H3 Ref2VA + AudioDrive；代价：整帧会重画，身份细节会漂） |

---

## 输入契约

| 槽位 | 节点 | 要求 |
|---|---|---|
| 原片 | `VHS_LoadVideo` | 单镜、无硬切；`frame_load_cap` 必须等于 `length`，且落在 **17k+5** 网格 |
| 首帧 | `LoadImage` | 从原片抽第 0 帧；锁两人身份与服饰用 |
| 配音 | `LoadAudio` | mp3/wav 单声道人声；长度可以短于 `length`（尾部自动补静音，后期裁掉） |
| 提示词 | `PrimitiveStringMultiline` | H3 Ref2VA 六段式，必须按 `h3-prompt-writing/references/ref-en.txt` 写 |
| 画幅 | `PrimitiveFloat ×2` → `ComfyMathExpression` | 32 的倍数，且**与源片同比例**，否则被拉变形 |

## 拓扑（28 节点 / 31 连线）

```
VHS_LoadVideo(90 帧) ─────────────┐
LoadImage(首帧) ──────────────────┤
                                  ├→ MiniMaxH3ReferenceToVideo → positive ─→ BasicGuider
CLIP / VAE / audio VAE ───────────┘                        └ LATENT ─┐
LoadAudio ─────────────────────────────────────────────────────────┤
VAE(audio) ────────────────────────────────────────────────────────┴→ VRGDG_MiniMaxH3AudioDrive
                                                                        ├ audio_driven_av_latent → SamplerCustomAdvanced
                                                                        └ original_audio ───────→ VHS_VideoCombine.audio
Sampler → VAEDecode → VHS_VideoCombine(24fps, 音轨 = 这条配音)
```

模型：UNET `minimax_h3_ref2va_int8_convrot` + LoRA `minimax_h3_turbo_4step_ckpt500`(1.0)；CLIP `qwen3vl_32b_minimax_h3_int8_convrot`；视频 VAE fp16 + 音频 VAE fp32。

**关键差别**：音频不是写进提示词，是 `VRGDG_MiniMaxH3AudioDrive` 直接写进 `av_latent`；`VHS_VideoCombine` 的音轨也取该节点的 `original_audio`（第 1 槽），所以成片音轨就是上传的那条配音，不用另配。

## 默认参数（本片实测这套能跑）

| 参数 | 值 | 理由 |
|---|---|---|
| 画幅 | 864×736 | 与源片同尺寸、32 的倍数 |
| 帧数 | 90 | 17×5+5；音频 3.336s → 最近网格是 90（3.750s），尾部 0.41s 静音 |
| 步数 | beta 4 步 + `H3SigmaRefiner`(0.7 以下 +2) / `SplitSigmas` 4 全给一采 | 4 步 turbo 的标配；参考服从性弱于 20 步 |
| 种子 | 20261117 fixed | 换版本改 `build.mjs` 顶部 `SEED` |
| 输出 | `shot2_h3_voice`，24fps，crf 19 | 一采直出，无放大 |

## 实测（2026-11-17，taskId `2122472054728118274`）

- 源片 `05_shot2.mp4`：864×736 / 81 帧 / 3.375s；先 `tpad` 克隆末帧补到 90 帧再当参考
- 配音 `胡宗宪_内阁通过.mp3`：3.336s / 24kHz / 单声道，台词「皇上，内阁已经一致通过了」
- 出片：**864×736 / 90 帧 / 3.750s / 716 KB**；自检 28 节点 / 31 连线 / 红 4 橙 1 通过
- **全帧帧间差均值 0.707（峰值 2.548，n=89）** —— 镜头本身几乎不动，和源片一致
- **右半区（含右侧听者）帧间差 0.020–0.746** —— 右侧人物基本静止
- 嘴部 15 帧拼条：张开 / 收圆 / 闭合来回变化，无定格嘴；左边人物逐字开合
- 音频：`mean −31.4 dB / max −11.1 dB`；`silencedetect` 句尾静音起点 **3.194s**，与音频 3.336s 对齐（差异来自重编码）
- 身份保真：成品首帧 vs 源片首帧 **PSNR Y 17.17 / U 29.90 / V 23.38 dB** —— 构图、机位、服装大形对，**胡须长度与官帽纹样被重画**
- 交付：裁到 81 帧 / 3.375s，与源镜头等长

## 已知限制

1. **整帧重画**：4 步 turbo 下身份细节会漂（本片左官胡须变短、帽纹改写），要更贴就改 20 步一采（成本约 5 倍）。
2. **平台水印会被洗掉**：源片右上角「RunningHub AI生成」在成品里消失，需要水印的话后期另叠。
3. **17k+5 决定时长的取整方向**：音频 3.336s 只能取 90 帧（3.750s），尾部多出静音必须裁；想正好等长就先裁音频到网格内。
4. **源片帧数不在网格时先补帧**：`tpad=stop_mode=clone` 克隆末帧到 90，否则 `length` 与 `ref_video` 帧数不一致。
5. **双人同框的嘴部归属靠提示词压**：说话人写 `<Subject N> (Sx)` 且 `<d>` 紧贴他；听者用**一句正向静止嘴形** + 「he is a listener」，别堆否定句（堆了嘴反而动）。
6. **`ref_images` 上限 2 张**；本包只用 1 张首帧。

## 复用步骤

1. 拿本目录 `workflow.ui.json` 拖进 RunningHub「导入工作流」。
2. 拍四个红块：原片、首帧、配音、提示词（说话人换 `<Subject N> (Sx)`，听者写静止嘴形）。
3. 量源片宽高与音频秒数：改 `build.mjs` 的 `FRAMES`（17k+5）与 `WIDTH/HEIGHT`（32 倍数、同比例），`frame_load_cap` 自动跟随 `FRAMES`。
4. 跑完抽 0 / 1.5 / 3.0 秒三帧 + 一段嘴部拼条验收：说话人逐字开合、旁人嘴形不动、官帽胡须不变形、镜头没推拉。
