# H3 五人换人 · 两镜硬切（特写 + 四人圆桌）· 一采（已入库）

**状态**：已入库（2026-11-14 老板平台跑通、确认可用）
**适用场景**：**一条 3–4 秒、内部含一次硬切的短片段**——前镜是一个人占满画面的极特写（先笑后怒、唯一说话者），后镜是四个人并排坐着的圆桌镜头。5 个人各用一张参考图整身换掉，保留原机位、裁切、表演、音轨与两镜结构；864×736 一采直出，不做放大。

## 1. 它做什么

把一段 3.75 秒、共 90 帧的董事会戏换成 5 个明制袍服人物：

- **第 1 镜（0.000–3.417s 原片）**：诺曼单人极特写，左三分之四侧脸朝右，先咧嘴笑约 1.5 秒，再皱眉怒吼。原片是金棕背头、蓝眼、炭灰西装、白衬衫、蓝领带；换成 `人物2` 的黑长发 + 金冠 + 冰蓝袍 + 白内领，头顶被上框裁掉，金冠只露下沿。
- **第 2 镜（3.417–3.750s 原片，仅 8 帧）**：硬切四人圆桌，四人都不说话（原片这段接近静音）。左边缘半张脸、中左最大体量、中右偏后、最右边缘半身，四人各换一张。

与 `H3-七换一留-董事会宽景-一采` / `H3-九人换人-…-服装模板锁袖-一采` 的区别：**这是库里第一个「一镜内硬切」的包**，也是第一个把参考图缩到 5 张的包（前两包分别 7 张、9 张）。参考图少，单张脸分到的权重更高，脸更像。

## 2. 拓扑

```
UNET(ref2va int8) → turbo 4步 LoRA → SageAttention → 显存补丁
  ├→ BasicScheduler(beta,4) → H3SigmaRefiner(+2, 0.7, cosine) → SplitSigmas(4)
  │     → 一采 4 步 @864×736（全部步数给一采）
  └→ BasicGuider ← MiniMaxH3ReferenceToVideo
        ref_images 0..4 = 人物2 / 徐阶 / 高拱 / 张居正 / 严世蕃
        ref_videos 0 / ref_video_audios 0 = 原片画面与声音
一采 → VAEDecode → VHS_VideoCombine(24fps, audio ← 原片音轨)
```

30 节点 / 33 连线，红块 7 / 橙块 1。

关键点：

1. **没有放大支路**：无 `MinimaxH3LatentUpscaler3D`、无第二 Sampler。
2. 输出走 `VHS_VideoCombine` 的 `audio ← VHS_LoadVideo`，成片音轨是原声。
3. 模板只声明 `ref_image_0..3`，**第 5 个槽位由 `build.mjs` 插进节点**（插在 `ref_videos` 之前，顺序即 Picture 序号）。
4. 硬切不靠接线，只靠提示词里的 `[Shot 2] At 00:03.417`。**H3 会自行决定切点位置**，见 §6。

## 5. 提示词合规（h3-prompt-writing / ref-en.txt）

- 六段顺序：`subject_definitions` → `summary` → `retention_analysis` → `detailed_description` → `overall_soundscape` → `non_diegetic_music` ✓
- 任务类型 `[video editing + audio reuse]`，summary 以 “The target video is an edited version of `<Video 1>`.” 开头 ✓
- 两镜：`[Shot 1]` 无时间戳，`[Shot 2] At 00:03.417` 标切点 ✓
- 唯一说话者写 `<Subject 1> (S1)`；第 2 镜四人明确写「都不说话、嘴闭着」✓
- 逐人写死袍色 + 帽形 + 胡须 + 可见范围，并把原片西装整体标 `not_retained`；补「布料哑光、不发光、无霓虹边」✓
- **本包没写 `<d>` 台词**：源片是英文对白，本地 sherpa-onnx ASR 未启动成功（venv 缺失），未花额度跑 stt。口型靠参考视频驱动，能对上调门但逐字口型不保证。要精确口型就补 `<d>[English] ...</d>`。

## 6. 已知限制

1. **切点不受控**：提示词写的是 00:03.417，实际切在 ≈1.875s（第 46 帧）。H3 对「一条片里切一刀」的时点控制很弱，原片第 2 镜只有 8 帧（0.33s），模型显然不接受这么短的镜头，把它拉到 1.8s。**要严格按原时长交付，别用这个包**。
2. 四人镜头被拉长后，画面比原片更「近」：桌面前景的茶杯、文件夹占比更大，左侧女士露出的脸比原片多。
3. 第 2 镜左边缘的徐阶是原片女性位置换男性，靠半脸 + 一只手上移维持裁切；要求「露全脸」的场合不适用。
4. 高拱保留原片的细框眼镜（参考图里无眼镜）——这是刻意的，用来锁人物轮廓；要求完全照参考图的场合要删掉这句。
5. 5 张参考图下脸部相似度明显好于 7 张 / 9 张，但第 2 镜四人脸只占 80–140px，仍属中等相似度。
6. 参考图 `fileName` 约 24 小时过期；报「找不到图」就重传换 `ASSETS`，接线不动。
7. 本包**没有二采支路**，要放大交付请先按 `H3 二采 · Ref2VA` 改接线。

## 7. 复现

```bash
node build.mjs                 # 读 prompt.txt + templates/base_onepass.ui.json → workflow.ui.json
node check.mjs                 # 结构自检 + 导出 workflow.api.json
node <runninghub-cloud-yashu>/scripts/rh.mjs --upload "<本地图>"   # 换新 fileName 后改 build.mjs 的 ASSETS
```

改参数只动 `build.mjs` 顶部：`FRAMES` / `WIDTH` / `HEIGHT` / `SEED` / `OUT_PREFIX` / `ASSETS`；提示词只改 `prompt.txt`，**不要手改 workflow.ui.json**（下次 build 会覆盖）。
