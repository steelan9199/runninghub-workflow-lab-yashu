# H3 九人换人 · 董事会宽景 · 服装模板锁袖 · 一采

**适用场景**：一镜到底、固定机位、无剪切、无人起身的会议／朝堂宽景，**9 人同框**——8 个人整身换装，第 9 个人只露一条前臂，靠一张服装模板图把袖型、材质、滚边锁死。864×736 一采直出，尺寸＝出片尺寸，不放大，原声 1:1 复用。

## 拓扑

`LoadVideo`（原片 {video}）→ `MiniMaxH3 参考生视频`

- `ref_videos.video` ← 原片（运动参考）
- `ref_images.ref_image_0..8` ← 9 张：8 张人物图 + 1 张服装模板
- `frame_load_cap` = `length` = **73**；宽高经两个 `→ INT` 节点送进模型
- 采样：一采 4 步 beta，`H3SigmaRefiner(+2, 0.7, cosine)`，`SplitSigmas(4)` 全给一采
- 解码：`VAEDecode` → `VHS_VideoCombine`（24fps / h264-mp4 / crf19 / yuv420p / **原片音轨**），H3 自编声轨丢弃

- 源片：864×736 / 73 帧 / **3.042s** / 24fps；音频 **mean −18.0 dB / max −0.9 dB**（有对白）
- 成片：864×736 / 73 帧 / 3.042s；H.264 crf18 本地重编码 611 KB；AAC 44.1k 双声道 3.018s
- 帧间差（`tblend=difference` + `signalstats YAVG`，72 对）：**平均 0.658 / 最大 1.115 / 最小 0.110**
- 结构自检：`check.mjs` ✓（红 11 / 橙 1；红块数超 6 属已知妥协）
- 视觉验收：九人各对其参考图不串脸；前景虚焦后脑勺仍无脸；黑白边保留；舞台背景（OSCORP 墙／茶杯／空椅）无漂移

## 已踩的坑（重要）

1. **极小局部改色，H3 不响应**。「白袖口改成红袖口」连跑两版，袖口仍是白的；必须把**整件服装**当参考图进去重画（本包 `Picture 9` 就是干这个），否则只能后期上色。详见 `references/pitfalls.md`。
2. **服装必须逐人写死**（袍色＋帽形＋胡须＋可见范围）。只写「整身取自 `<Picture N>`」在宽景里必失败。
3. **别堆材质词**：一句里三个以上 `gold/dragon/embroidery` 会出绿荧光与橙火焰；补「哑光、不发光、无霓虹边」。
4. **参考图 9 槽已满**，再加人必须删一张或拆两轮。

## 已知限制

- 只露后脑勺／一条前臂的人：脸永远验不了，只能验袍色、冠、袖型。
- 3.04s 在 H3 训练区间（4–15s）之外，表演幅度有限，别硬加戏。
- 三视图参考图（2304×1024）会被平均；正面主角建议换单人正面白底立绘。
- 平台 `fileName` 约 24 小时过期；报「找不到图」不是接线错，重传后改 `ASSETS`。
- 有对白时若提示词不写 `<d>` 台词，嘴可能不动；本包未做 STT，属已知风险。
