# 角色三视图（备选）

> **2026-11-19 起降级为备选**：三视图首选入口改为 `MOSS三视图-白底三格-批四`（MOSS-Image int8 + DMD 8 步，一次出 4 张）。本包仅在 MOSS 出图失败、缺模型或需要对照时使用。

**一句话用途**：以后要出「白底三栏角色三视图」（左＝正面脸特写 / 中＝无头人台 / 右＝背面全身），就用这一条——Qwen Image 2.1 文生图单模型一次出 4 张候选，挑一张。

**入口约定（2026-11-19 老板定）**：三视图首选 `MOSS三视图-白底三格-批四`，本包为备选；`character-threeview-yashu` 技能已加废弃声明，不再作为三视图入口（那套四步编辑链只在「中格反复长头、本包彻底压不住」时作兜底参考）。

## 拓扑

```
UNETLoader qwen_image_2.1_bf16_Raw → KSampler.model
CLIPLoader qwen3vl_8b_int8_convrot (type=qwen_image) → TextEncodeQwenImage21.clip
TextEncodeQwenImage21 ─ positive → KSampler.positive
                     ─ negative → KSampler.negative
EmptyLatentImage 1728×768 batch=4 → KSampler.latent_image
VAELoader qwen_image_2.1_vae_bf16 → VAEDecode.vae
KSampler → VAEDecode → SaveImage
```

9 节点 / 8 连线。**没有 QwenImage21Cache**（平台每次任务可能落到不同机器，少一个可选节点少一分缺节点风险），也**没有参考图输入**——版式完全靠提示词固定，换角色只改「主体 / 服装」两行。

| 画幅 | 1728×768（三格各 576×768） | 每格 3:4，与参考版式同比例；两边都是 16 的倍数 |

| 提示词 | 663 字中文，九行结构 | 三栏契约写在第一行，逐格分别点名；左格带硬裁切句 |

## 三栏契约（提示词已写死，改词时别丢）

- 左：**头部特写**，只拍头、颈、肩与锁骨，下缘止于锁骨下方一寸；脸部放大到头顶—下巴约占本格高度 2/3；不出现胸口、腰线、手臂以下、衣裙与双腿；头部完整、两侧留白；
- 中：正面全身的**服装展示无头人台**，圆领以上纯白，不许补头、不许画脖子断面；
- 右：背面全身，完整带头与发型，看不到面部；
- 整体：三格等宽、同一套服装、同一站姿、同一脚底线、纯白底 #FFFFFF、无文字/编号/水印。

**左格必须写「硬裁切」（2026-11-19 补）**：只写「胸部以上特写」压不住——遇长裙、宽摆、连体衣时，服装行会把左格拉成全身或半身。必须同时写死下缘（锁骨下方一寸）、排除项（胸以下 / 腰线 / 双腿 / 衣裙），并在版式段加一句「左格头像明显大于中右格的全身像」。实测：改前 3 条里 2 条左格跑成大腿以上，改后 3/3 回到头部特写。

**中格「无头」只能靠正向描述压**（写「服装展示专用的无头人台，圆领以上是纯白背景」，不要写「不要头」——cfg=1 时负向是死参数，正向里的否定句也会反噬）。

## 已知限制

1. **中格偶发长头**：本次 4/4 通过，但换人设、换发型或换种子后可能复现。只改提示词压不住时，按 `character-threeview-yashu` 的返工表做无头人台单独出图，再合成——不要盲目连跑。
2. **中格丢外套**：提示词服装行要写全，且三栏分别点名风衣；批量出图时逐张核对服制一致，别只看脸。
3. **bf16 更吃显存**：大图或高批次在小卡实例上可能 OOM；真遇到把 batch 降到 1–2。
4. **画幅两边必须成对改**：宽高都是 16 的倍数；改比例时三格比例会跟着变，参考版式是每格 3:4。
5. 包内 `check.mjs` 的提示词关键词与目标比例是按本包契约写死的（`三格 / 无头人台 / 背面全身 / 纯白背景`，2.25）；换契约要同步改，否则误报（见 pitfalls.md「工作流包复用」）。
