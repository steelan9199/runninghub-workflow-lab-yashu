# H3-Image 角色三视图 · 多参考图直连

**一句话用途**：已经有一批某角色的视频截图（脸特写 / 正面全身 / 背面全身，最好再补半身、发饰），要**出这个人的**白底三栏三视图（左＝脸部特写 / 中＝无头正面全身 / 右＝背面全身）——用这一条。身份由参考图锁，不是凭空捏人。

## 入口分流（先看这条，别选错包）

| 你手上有什么 | 走哪个包 |
|---|---|
| **某角色的多角度截图**（要"还是这个人"） | **本包**：H3-Image + 多参考图直连 |
| 只有文字人设，没参考图 | `MOSS三视图-白底三格-批四`（首选）/ `角色三视图`（Qwen，备选） |
| 要一次出 4 张候选挑一张 | `MOSS三视图-白底三格-批四` |

三者输出都是「左脸特写 / 中无头 / 右背面」，区别只在身份来源：本包靠参考图，另两个靠提示词。

## 拓扑

```
UNETLoader  minimax_h3_image_pruned_bf16
CLIPLoader  qwen3vl_32b_minimax_h3_int8_convrot (type=minimax)
VAELoader   minimax_h3_image_vae_fp16
LoadImage ×3 (正面全身 / 脸特写 / 背面全身)
        └→ MiniMaxH3ImageConditioning.images.image_0 / image_1 / image_2
           + prompt（三栏契约）+ width/height 3168×1280
                ├→ positive → BasicGuider
                └→ LATENT    → SamplerCustomAdvanced.latent_image
RandomNoise(42) / KSamplerSelect(euler) / ManualSigmas(6 档) → SamplerCustomAdvanced
SamplerCustomAdvanced → VAEDecode → SaveImage
```

15 节点 / 15 连线（UI）。采样与模型是官方 MiniMax H3-Image 定死的：`euler` + 6 档 sigmas，CFG=1，无负面提示词。

## 输入要求（最低 3 张）

1. **image_0 = 正面全身**（主图 / Picture 1，模型以它为"编辑底图"，决定站姿与服制基准）
2. **image_1 = 脸部特写**
3. **image_2 = 背面全身**
4. 可选补：正面半身（看清服装细节）、背面发髻/飘带——复制 LoadImage 接到 `参考图 4/5/6`，最多 16 张。

## 选图经验 / 避坑（从 14 张剧截图里只挑 5 张的真实过程）

> 这一段是这套工作流最容易翻车的地方：**接线只值 20 分，选图值 80 分**。

**0. 先建清单再挑。** 逐张看，给每张打 4 个标：① 部位/角度（脸特写 / 半身 / 全身 / 正面 / 背面 / 3⁄4）；② 画面里有没有第二个人或路人；③ 主角有没有拿道具；④ 字幕压在哪。**不按文件名顺序挑。**

**1. 硬否决项（命中就淘汰，别心疼）：**
- **画面里有第二个人/路人**：会把路人的脸、衣服、体型混进三视图，甚至某一栏多画出一个人。本次 `(3)(12)` 有渔夫、`(3)(13)` 有摊主和两个女人，全淘汰。
- **主角拿明显道具**（斗笠、酒杯、鱼竿）：道具会被带进三视图，还挡袖口和手。本次 `(3)(9)` 举杯、`(3)(13)` 提斗笠，淘汰。
- **关键部位被画框裁断**：脚被裁、头顶被裁、半边身子出画——全身栏不能用。
- **强 3⁄4 侧脸 / 低头 / 仰头**：正面脸特写会歪。本次 `(3)(3)` 抬头、`(3)(7)` 微侧，只做补充，不做主脸。
- **背景杂物多且贴人物**：宫墙、山景、栏杆树影会渗进白底。
- **不同服装/不同集数**：不能混用，三栏服制会打架。

**2. 主图（image_0）怎么选**：优先级 = 单人 > 正对镜头 > 全身完整 > 背景相对干净 > 分辨率大。本次选 `(3)(10)`（正面站姿、单人、长袍到脚），淘汰 `(3)(12)`（有渔夫）和 `(3)(9)`（举杯 + 偏 3⁄4）。

**3. 背面怎么选**：必须"单人 + 直背 + 头发/发饰完整"的背面全身。`(3)(11)` 合格；`(3)(1)/(3)(4)` 只有上半身，不能当全身背图；`(3)(2)` 只有后脑勺，只能当发饰细节补图。

**4. 脸特写怎么选**：正脸、眼睛看镜头、光线均匀、五官不被头发大面积遮挡。`(3)(5)/(3)(8)` 最稳；`(3)` 是 3⁄4，只做补充。

**5. 补身份图（可选）**：半身正面 `(3)(6)` 看清道袍纹样 + 白内领；`(3)(2)` 看清发髻 + 飘带。接到 image_3/4，别占主图位。

**6. 字幕**：这批剧截图字幕都在底部同一带（约高度 8–10%）。可裁掉底部，也可原样喂并在提示词写 `no subtitles`。本次按老板要求"原图直接喂"，模型没有复刻字幕；但字幕压在人物身上时必须换图。

**7. 数量与顺序**：3 张是下限（脸 + 正 + 背），5 张最稳（+ 半身 + 发饰）。顺序固定：image_0 正面全身、image_1 脸特写、image_2 背面全身。

**8. 一致性复核**：把选中的几张并排看一遍，确认同一个人、同一套服装、同一发型、同一时代背景。宁可少一张，不要混进不同造型。

**9. 分辨率**：优先原尺寸大图（2MB 以上）。人物在画面里太小、脸只有几十像素的，放大后五官会糊，模型会自己"编脸"。

**10. 不是越多越好**：超过 6 张后，多余角度会稀释主图站姿与服制，三栏反而容易不一致。先 3 张跑通，再按缺口补。

## 三栏契约（提示词已写死，改词时别丢）

- 左：**脸部特写**，头部完整、发型元素齐全、正视镜头；
- 中：正面全身的**无头人台**，领口以上纯白，不许补头、不许画脖子断面；
- 右：背面全身，**带头**与发型，看不到脸；
- 整体：三格等宽、同一身份/服制/比例、纯白底、无文字/水印/多余人物/背景景物。

**中栏"无头"只能靠正向描述压**：写 `everything above the robe collar is pure white, no head and no hair`，不要写"不要头"——CFG=1 时负向是死参数，正向里的否定句也会反噬。

## 已知限制

1. **参考图 fileName 1 天过期**：过期后节点报找不到图，不是接线错。用 `build.mjs` 重传即可。
2. **image_0 是"编辑底图"**：放错（比如放了背面或脸特写）整张版式会跟着跑偏。
3. **中栏偶发长头**：正向描述压不住时，把"headless / pure white above collar"再加强，或单独出一张无头人台当 image_3 参考。
4. **字幕/背景会渗**：原图直喂时，字幕或"别的人群"可能残留；成图出现文字就裁剪参考图底部或换图。
5. **画幅别乱改**：宽高必须 32 的倍数，面积别超 ~6MP。
6. **H3-Image 吃显存**：bf16 主模型 ~40GB + int8 编码器 ~27GB，小卡实例会 OOM。
