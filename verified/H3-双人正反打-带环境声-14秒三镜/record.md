# H3 双人正反打 · 带环境声 · 14 秒三镜

> 一句话用途：一条 T2VA 提示词里完成「双人全景 → 过肩正 → 过肩反」三镜正反打，中文对白 + 雨夜环境声，台词压过环境 11–13 dB。

## 状态

- 老板 2026-11-20 实跑确认，要求发布入库。
- 与 `H3-双人正反打-纯台词轨-14秒三镜` 并列：那包是**场景 A（纯人声）**，本包是**场景 B（带环境声）**。两者不是替代关系，按用途各取一个。

## 拓扑（23 节点 / 27 连线）

与场景 A 完全一致：`CLIPLoader → MiniMaxH3ImageToVideo`（首末帧留空）+ `VAEDecode` / `VAEDecodeAudio` 双路解码 → `CreateVideo → SaveVideo`，带 turbo LoRA 旁路开关。

唯一差别在提示词：本包在 `integrated_multimodal_description` 之后补了 `overall_soundscape` 与 `non_diegetic_music` 两段。

## 默认参数

- 1344×768，24fps，`duration=14` → 345 帧 = 14.375s
- `res_multistep` / `simple` / 20 步 / denoise 1，seed 20261120
- Turbo 开关 `false`
- 切点 `At 00:03.800` / `At 00:08.200`，台词收声时间 `00:06.800` / `00:11.800`

## 已知限制

1. 主镜头人物占画偏满，提示词里「下三分之一留暗」没有明显生效。
2. 收声后 12.6s / 13.6s 两帧几乎完全静止，姿态略僵——只写了「holding her gaze」，没给具体微动作。
3. 背景厨房明档有第三个人影（约画面左侧），属于场景穿帮。
4. 切点本版贴得很准，但不保证每次都准；H3 切点漂移是已知不可控项。

## 复现

```bash
node build.mjs     # 读 assets/prompt.txt + base.ui.json，生成 workflow.ui.json
node check.mjs     # 接线 / 重叠 / 控件格式 / 提示词结构自检
```

`workflow.ui.json` 是平台导入后回灌的版本（带平台侧 `id` 与前端元数据），节点槽位以平台为准。
