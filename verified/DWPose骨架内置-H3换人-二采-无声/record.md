# DWPose 骨架内置 · H3 换人 · 二采 · 无声

**一句话用途**：把一条真人舞蹈视频里的人整身换成参考图人物，**图内自动提骨架当第二路动作参考**，二采出高清无声成片。
骨架不再需要单独跑、也不用上传骨架文件——原片进图，DWPose 现提，直接喂给 H3。

> **实测状态：平台未实测。** 本条只有结构自检（32 节点 / 40 连线通过），成片还没跑过。
> 跑通后把实测数据补进来，再把 `verified/README.md` 里那一行的「未实测」改成正式数据。

## 拓扑（32 节点 / 40 连线）

```
原片 VHS_LoadVideo ─┬─→ ref_video_0（主：表演/构图/镜头/三镜两切）
                    ├─→ DWPreprocessor → ImageScale(640×544) → ref_video_1（辅：只给关节）
                    └─→ ref_video_audio_0（只喂模型，不出声）

人物三视图 LoadImage → ref_image_0

MiniMax H3（640×544 / 328 帧）
  → 一采 4 步（beta + 尾部加密 2 步，切分 4）
  → LTXVSeparateAVLatent → MinimaxH3LatentUpscaler3D（只放视频 2×）→ LTXVConcatAVLatent
  → 二采 2 步（1280×1088）
  → VAEDecode → VHS_VideoCombine（h264，音轨不接）
```

## 默认参数

| 项 | 值 |
|---|---|
| 原片 | `小丑02_328f.mp4`，864×736 / 328 帧 / 24fps / 13.667s |
| 一采 | **640×544**，4 步，beta + `H3SigmaRefiner`（0.7 以下 +2 步） |
| 二采 | **1280×1088**，2 步，`minimax_h3_latent_upscaler_3d_fp16_V2`，`mode=scale by multiplier`、`multiplier=2`、`align=32` |
| 音频潜空间 | 不放大，`sep` 出来直接 `cat` 回去 |
| DWPose | hand `enable` / body `enable` / face `disable`、`resolution=1024`、`yolox_l.onnx` + `dw-ll_ucoco_384.onnx` |
| 噪声 | fixed `20261115`，两采共用 |
| 输出 | 24fps、`video/h264-mp4`、`yuv420p`、crf 19、**无音轨** |

## 为什么一采是 640×544

四个约束同时满足才算合法：

1. **32 的倍数**（VAE 8× 下采样 + patch 2×）：864×736 本身是 27×32 / 23×32，但减半后 432×368 = 13.5×32 / 11.5×32，不合法。
2. **比例贴近原片 1.174**：640×544 = 1.176，偏差 **+0.2%**（672×576 −0.6%、704×608 −1.4%、736×640 −2.0%）。
3. **像素预算**：已验证二采包只跑 56–73 帧、一采 832×704（0.59MP）；本条 328 帧是它们的 4.5 倍，一采压到 0.35MP。
4. **2× 之后仍合法**：1280×1088 = 40×32 / 34×32。

## 提示词要点

- 两路参考在提示词里定义为 `<Video 1>`（主）与 `<Video 2>`（骨架），并写死「骨架只作动作参考，线条人/圆点/黑底一律不得画进成片」。
- 表情：人物2 全程**面无表情、不许微笑**——原片那道上扬红嘴角是妆，不是表情。
- 抽烟：明写「夹烟吸最后一口 → 甩掉 → 吐烟」，烟卷允许入画（老板后期自己打码）。

## 已知风险

1. **二采 + 328 帧未实测**，显存与耗时都是未知数；OOM 就退 576×480 → 1152×960，或按镜拆三段（107 / 124 / 90 帧）。
2. DWPose 的骨架是**按人物框归一化放大**的（见 `DWPose-视频转骨架-无声` 的实测），`ref_video_1` 里的骨架会偏大；若 H3 被带成中景，删掉 `dwp → skelscale → ref_video_1` 两根线退回单视频版。
3. 两处硬切仍只受语义级约束，切点可能漂。
4. 素材 `fileName` 约 24 小时过期，重传后改 `build.mjs` 的 `ASSETS`。

## 复现

node build.mjs && node check.mjs
